Clip Engine

A local desktop workspace for managing short-form content campaigns, clips, publishing workflows, and authorized platform analytics.

TikTok integration

Clip Engine uses TikTok Login Kit and Display API only after a user authorizes the connection. It reads account identity, follower statistics, public videos, and the metrics TikTok makes available for those videos.

The integration is read-only. Clip Engine does not scrape TikTok, automate login credentials, upload videos, or publish content through this integration.

Support

Clip Engine is a local-first tool. For questions about the application or data handling, use the contact method provided by the operator who supplied this app.
